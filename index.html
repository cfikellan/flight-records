How it works

Save Backup opens the Share Sheet: choose “Save Flight Records Backup.” Restore Saved Backup launches a separate shortcut named “Restore Flight Records,” which must be configured to copy your backup JSON to the clipboard. Return to this app; it will attempt restoration automatically. If iOS blocks it, tap Paste & Restore Backup. You can always restore a different file manually. Keep a separate recovery copy when possible.
